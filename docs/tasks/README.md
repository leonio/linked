# Task cards

One file per phase. Each card is written so that it can be done without reading the other cards.

Card layout:

- **Layer / Skills** - which project you touch and which skills to load first.
- **Depends on** - cards that must be ticked in `docs/PLAN.md` before you start.
- **Copy** - the existing code that is closest to what you are building. Read it first and imitate it.
- **Build** - exactly what to create. Names in `code font` are the names to use.
- **Tests** - the minimum tests. More is welcome; fewer is not done.
- **Not in this card** - things you will be tempted to do. Don't.

Every card ends the same way: run the verification in the `implement-task` skill, tick the box in `docs/PLAN.md`, commit.
